# 痛风不来扰 降尿酸好中药告诉您

> 更新时间：2026-09-17 (UTC+8)

如何防治痛风，降低尿酸呢？饮食调理是首选，这里就给大家介绍一些能降低尿酸的“好中药”，经常食用，痛风不来扰！
-----
-----

玉米须　
性平、味甘，不论体质寒热，均可服用，且口感极佳，价廉易得，可以泡水或者煮水喝，每天用量15g-30g。中医认为它清热、祛湿、利尿，对降低血尿酸疗效确切。
芹菜籽　
辛、苦，凉。目前研究发现芹菜籽提取物有很好的抗炎、镇痛和显著降低血清尿酸作用。它还有很好的降压作用，对于血尿酸升高伴高血压者，尤其适用，寒体慎用。
土茯苓　
性寒，味甘，田间或者路边易得，干品每天15g，鲜品每天50g，煮水饮，能促进尿酸排泄，有效降低尿酸，但寒体慎用。
薏苡仁　
性凉，味甘淡，每天15g-30g，用于煮粥或煲汤，可健脾、清热、祛湿，有效降尿酸，体寒者慎用。
蝉花　
又名金蝉花、虫花，甘，寒，无毒，每天5g-10g煲汤或者煮水喝，香甜可口，不仅可降尿酸，还可以护肾，尤其适用于高尿酸并有肾功能损害的患者。
樱桃 / 柠檬 / 山楂　
这三种是血尿酸升高患者最好的水果，可有效辅助降尿酸。柠檬、山楂味酸，却是碱性食物，泡水喝即可有效降尿酸，还可以降脂。
